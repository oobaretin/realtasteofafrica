# Search operators for finding African restaurants (Texas)

Use these in Google (or your search engine) to find new listings without an API.

## By platform and location

- `site:yelp.com "African" "Austin, TX"`
- `site:yelp.com "African" "Dallas"`
- `site:yelp.com "Nigerian" "Houston"`
- `site:instagram.com "Food Truck" "Nigerian" "Dallas"`
- `site:instagram.com "African restaurant" "San Antonio"`

## By event / recency

- `"Grand Opening" African Restaurant Texas 2025`
- `"New" Nigerian restaurant Houston 2025`

## By cuisine

- `site:yelp.com "Ethiopian" "Fort Worth"`
- `site:google.com/maps "West African" "Texas"`

Run these periodically, then add new spots to `data/restaurants.csv` and re-run `npm run import:restaurants`.
