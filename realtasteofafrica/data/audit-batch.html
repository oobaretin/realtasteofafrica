Audit restaurants

Open DevTools Console (Cmd+Option+J or F12), then run:

auditBatch(0, 10)   // first 10
auditBatch(10, 10)  // next 10
auditBatch(20, 10)  // etc.

Total: 281 restaurants. Each tab opens Google Maps — look for "Temporarily closed" or "Permanently closed". If closed, remove from data/restaurants.csv and re-run node scripts/audit-batch-html.mjs.

See docs/google-maps-audit.md for search queries to find new restaurants.
